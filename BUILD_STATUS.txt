ClasherCity 1.1.2 — build and verification status

RELEASE PREPARATION
- Maven project version and final JAR name are set to 1.1.2.
- plugin.yml and default config.yml identify version 1.1.2.
- Windows and Linux/macOS build scripts print the correct JAR path.
- GitHub Actions builds with Temurin Java 25 and Maven, then uploads target/ClasherCity-1.1.2.jar as the ClasherCity-1.1.2 artifact.
- README installation and dependency instructions are aligned with the current 1.1.2 metadata.
- Plugin website metadata points to the actual GitHub repository.

BUILD REQUIREMENTS
- JDK 25
- Maven 3.9+
- Internet access to the configured Maven repositories

Build from the project root:
    mvn -U clean package

Expected output:
    target/ClasherCity-1.1.2.jar

Windows:
    build.bat

Linux/macOS:
    ./build.sh

VERIFICATION LIMITS
The successful CI run above confirms the source compiled and the JAR artifact was packaged. It does not mean the plugin was runtime-tested on a Paper server; follow the test checklist before live deployment.

DEPLOYMENT SAFETY
- Install on a TEST server first, not the live Clasher Network server.
- Back up the test world, plugins/ClasherCity folder and WorldGuard data.
- Confirm WorldGuard, Vault, Multiverse-Core and an economy provider are installed.
- Reward command lists remain empty until exact third-party command syntax is verified.
- Follow the test checklist in README.md before live deployment.
