IMPORTANT: NO JAR WAS BUILT IN THIS SESSION.

The available build container has OpenJDK 21 and does not have Maven or the Paper/WorldGuard/FAWE/Vault dependency artifacts. Paper 26.2 requires Java 25. Therefore it would be misleading to provide a JAR or claim compile/runtime verification here.

BUILD ON A MACHINE WITH:
- JDK 25
- Maven 3.9+
- Internet access to the configured Maven repositories

Then run from this project directory:
    mvn -U clean package

Expected output:
    target/ClasherCity-1.0.0.jar

On Windows, run build.bat. On Linux/macOS, run ./build.sh.
A GitHub Actions workflow is included at .github/workflows/build.yml; push the project to a GitHub repository and run the Build ClasherCity workflow to compile and download the JAR artifact.

DEPLOYMENT SAFETY
- Install the resulting JAR on the TEST server first, never directly on the live server.
- Back up the test world, plugins/ClasherCity folder and WorldGuard data before testing.
- Reward command lists are intentionally empty until the exact Infinity Caves and SmartSpawner commands are confirmed.
- Run the test checklist in README.md before considering live deployment.
